## 编辑入口

在本地页面左侧选择“动画编辑”。沿用姿势编辑中的身体圆点、彩色轴和旋转环，不需要换软件。也可以在“动作分解”暂停后点“编辑动画 · K帧”，从当前画面开始。

若要试用整圈数学生成，在“动作分解”右侧选择“数学轨迹 · 试验版”，用同一时间轴与保存动画对比，详见 [periodic-flare.md](periodic-flare.md)。数学试验独立于下面的固定帧和 K 帧，进入动画编辑会回到保存序列。

画布下方的时间轴始终可用，收起侧栏后仍可操作。白色菱形是已保存的原第 09–16 步和重复第 09 步；蓝色菱形是新增中间关键帧。原有九个节点的位置和编号保留，新增帧只控制它所在的两步之间的过渡。

**要修改已有固定姿态**，点白色菱形，或左侧当前段的“编辑原第 xx 步”。直接移动／旋转身体控制点，再按 **K** 或“更新原关键帧 · K”。它更新原位置的姿态，不创建新步骤；已有中间 K 帧和补帧设置保留，前后相邻区间随之重新生成，影响范围以最近的中间 K 帧为界。原第 09 步的首尾两个位置一起更新，始终闭环。修改用于这个浏览器中的正式播放和姿势编辑，项目的原始 JSON 导出和内置来源文件保留。未作调整时，更新按钮保持禁用。

**要调整中间过渡**：

1. 拖时间轴到问题画面，或在左侧选一段过渡，从中点开始检查。
2. 点身体控制点，像之前一样移动或旋转。肘、膝的移动用于调整弯曲方向，旋转会带动前臂或小腿；腰部可独立弯腰。右上“调整”可打开厘米和角度微调。
3. 按 **K**，或点画布下方“保存关键帧 · K”。再次停在已有蓝色帧上，K 会更新该帧。保存后，从前一个关键姿态到这帧、再到后一个关键姿态的两侧过渡都会重新生成；提示显示此次影响的秒范围。若附近另有已保存帧，重建范围以它们为界。单段预览和完整播放使用同一结果。
4. 按 **空格**播放／暂停；**← / →** 每次前进或后退 1/60 秒。下方可选择“当前段循环”或“完整循环”，速度可降至 0.1×。

右侧顶部“关键帧之间自动补帧”可选 **线性 · 匀速** 或 **平滑 · 缓入缓出**。线性模式在相邻两个已保存帧之间按时间匀速插值；平滑模式沿用原步骤之间的缓入缓出。你只需调整并 K 关键姿势，中间画面自动生成；新增帧会把所在过渡分成更短的区间。设置立即用于单段和完整播放，可撤销、刷新恢复，也会随过渡 JSON 导出。已有过渡数据继续使用原平滑模式，关键帧保存值保留。

键盘快捷键在输入框以外生效。G 移动、R 旋转，Ctrl+Z 撤销当前姿势调整。逐帧走到原节点时也可以直接调整并更新；白色帧更新原姿态，蓝色帧更新已有中间姿态，其他时间保存新的中间 K 帧。

髋部圆点与“髋部 · 独立位置与旋转”用于单独摆骨盆。移动时肩中心保持原位置、腰部配合弯曲；旋转时上身的位置与方向保留。超出腰部或四肢可达范围会限幅。整体挪动／转身选“躯干”，单独弯腰／扭腰选“腰部”；这些调整仍按原位置保存或更新 K，轨迹预览与播放读取同一姿态。

先少量补帧：在明显出错的位置摆一帧，再慢放观察两侧；仍不对时再补帧。无需把每一帧都重新摆一遍。脚部位置路线也可直接拉弧线，膝盖弯向和身体朝向继续由保存的姿势指定；辅助线帮助检查当前结果，不能自动判断正确托马斯动作。

## 恢复不满意的原帧

需要先保存整份当前动画时，可用 **导出动画 JSON**；也可展开 **复制／粘贴动画备份**，点 **生成完整备份** 后复制 JSON 到本地文件。完整备份包含当前原姿态、中间 K、脚部弧线、智能路线、跳帧和暂存。生成前须先应用或取消整段预览，避免把临时路线误当作已保存结果。将完整动画 JSON 粘贴回来，点 **载入这份备份** 可恢复；它使用同一导入校验与撤销流程。旧姿势库 JSON 仍只进入下面的按帧恢复选择。

展开右侧 **恢复原关键帧**，勾选要取回的原步骤，例如 09、10、11，再点 **恢复勾选的原帧**。默认来源为项目初始保存姿态；**读取姿态备份 JSON** 可以选择 `托马斯/9.json`、`10.json`、`11.json`、`16.json` 等旧步骤导出，也可读取正式展示或含原帧的完整动画备份。按姿态身份匹配，未匹配的步骤不能勾选。备份文件名不代表单帧编号，系统不会按文件名或列表顺序猜测对应关系。

只更换勾选原帧的姿态，原编号、名称、顺序与时间位置保留；首尾同一个第 09 步同步取回。其他原帧、中间 K、脚部弧线、补帧与跳过设置、暂存继续保留。恢复前完整动画先存入独立的浏览器备份记录，失败时不继续替换姿态；**下载恢复前备份** 导出最近一次恢复前的完整动画。**撤销动画修改** 可回退此次恢复，刷新后也可撤销最近一次原帧替换。个人步骤库与原始 JSON 文件不被修改。

旧步骤文件的格式是 `flare-pose-library`，与完整动画的 `flare-transition-edits` 不同。现在普通 **导入动画 JSON** 读取旧姿势或正式展示备份时，也会打开以上选择界面；读取只准备候选姿态，点击恢复才保存。原有完整动画备份仍按原入口导入。

## 拉脚部弧线

这是此前直接指定脚踝目标路线的工具，入口收在右侧 **脚踝目标弧线**，与下文从真实轨迹反求已有姿态分开使用。展开后点 **拉左脚弧线** 或 **拉右脚弧线**。系统选择当前两侧最近的启用关键帧；恰好停在某个关键帧时选下一段，编辑时间轴末端选上一段。右侧会写出两端原步骤或 K 帧及时间，进入后停在该段中间，便于观察。

拖动场景中的弧线中点或彩色轴，改变脚抬高、侧摆和前后绕行的幅度。下方“弧线中点”厘米数值也可微调。两端脚的位置固定，中点决定一条二次曲线；松手或数值修改确认后自动保存，按 **K** 也可保存路线，不新增或更新姿态帧。想指定更复杂的路线，可先添加中间 K，再分别调整两段弧线。

进入拉路线时只显示弧线控制点，脚的朝向、髋部和其他关节继续采用已有补帧。膝盖依据原弯向和骨长求解；弧线不是关节旋转控制。腿长和脚不穿地等约束继续生效，无法到达自绘目标时，实线表示实际脚踝路线，淡虚线表示目标路线，右侧显示最大偏差。可旋转视角、调低播放速度并循环当前段检查。

点 **返回摆姿** 或在未拖动时按 **Esc**，回到原来的身体控制点；拖动中按 Esc 只取消这次拖动。点 **恢复自动路线** 删除当前脚在这段的自绘弧线，恢复原补帧算法。“撤销路线调整”、Ctrl+Z 或“撤销动画修改”可回退已保存的路线；撤销历史按动画修改顺序回退。进入前未按 K 的姿态会暂存，仍可从左侧“回到暂存的调整”取回。

左右脚可分别保存弧线，刷新后保留，动画 JSON 导出／导入也包含它们。“启用过渡调整”关闭时，K 和自绘弧线一起停用。弧线绑定两端帧的身份，仅在它们当前相邻时生效；插入 K、跳过端点或删除端点 K 后，旧弧线保留但不误套到新的区间，两端再次相邻时可以恢复。修改两端姿态后，弧线随新的脚部端点重建，保留中点相对偏移；原步骤编号、时间和 9 秒周期不变。

## 跳过一帧比较自动补全

在下方时间轴点一个白色原关键帧或蓝色中间 K，再点 **跳过此帧**；右侧也有同名按钮。此帧立即停止参与补帧，系统连接前后仍启用的关键姿态，单段／完整播放和轨迹线使用同一结果。可以连续跳过多帧；时间位置、总周期、编号及原姿态保留，至少保留一个启用的关键帧。普通补帧位置没有独立保存姿态，需先选白色或蓝色帧。

已跳过的菱形变灰并带叉，仍可点选；当前画面显示系统在该时刻补出的姿态，方便比较。点 **恢复此帧** 会重新使用原保存姿态。如果在这个补帧画面上修改并按 K，则更新这个位置的姿态并恢复它，临时轨迹也按恢复后的关键帧预览。跳过前未按 K 的修改会继续暂存，可从左侧“回到暂存的调整”找回。

重复的首尾第 09 步同步跳过和恢复。跳过首尾后，从上一圈／下一圈仍启用的关键帧连接闭环，轨迹范围标为“跨循环”；9 秒周期保留。完整循环预览也播放 8–9 秒的新补帧，暂停到编辑范围外时回到编辑时间轴末端 8 秒。

跳过与恢复可用“撤销动画修改”回退，刷新后保留，导出／导入动画 JSON 也包含这些状态。原姿态与个人步骤不因跳过被删除。“启用过渡调整”控制中间 K 是否参与补帧，原帧的跳过状态独立生效。若操作会使有效关键帧全部消失，页面保留当前动画并提示至少保留一帧。

## 选择两帧检查实际关节轨迹

右侧“轨迹辅助线”中的 **起点／终点** 可以自由选择原固定姿态或已保存的蓝色 K，例如原第 09 步到原第 10 步，或原第 09 步到原第 11 步。选 09→11 时，第 10 步及范围内的所有启用 K 仍参与实际播放，不会改成只用 09 和 11 补帧；选择观察范围也不会跳过或修改任何姿态。点“跟随当前相邻帧”回到自动范围。

轨迹通过当前保存动画的完整算法求解，使用原帧／K、跳过状态、线性／平滑速度、四肢路线、自绘弧线、锁手、固定骨长和地面约束。已跳过或已停用的保存帧仍可作为观察边界，曲线显示它那个时刻实际补出的骨架；范围选择不会恢复它。终点早于起点时，按动画正向展开到下一圈，例如 16→10；原第 09 步的起点与末帧分别列出，9 秒周期保留。下方“所选范围循环”播放这整个观察范围，“完整循环”仍播放整圈。

默认显示全关节：骨盆、髋、肩、肘、腕、膝、踝和头颈。腰部控制点、手掌接触点、脚尖参考点在下拉标签中明确区分，它们没有独立的骨关节自由度。左右指人物本人，左侧蓝、右侧橙、骨盆青色。大圆点标出保存帧时刻，箭头表示前进方向；“重点检查”突出某一个关节，其他线路淡显。取消“全关节”后，可只看脚踝、膝盖和骨盆。

## 从轨迹纠正已有姿态

这项逐个修正保存姿态的入口现在收在右侧 **从轨迹修正关键帧** 中，展开后使用下面的步骤。整段路线调整见下一节。

1. 选择观察范围，再从“重点检查”选一个关节。可点击它的实际路线定位问题时刻，也可拖动时间轴定位。
2. 在“将修正的已有关键帧”中选该时刻真正参与补帧的前／后关键帧。恰好在保存帧时，只修正它本身。点 **选中轨迹点 · 开始修正**。
3. 拖动场景中该轨迹点的彩色轴，或用下方“实际轨迹点”厘米数值微调。系统反求选定帧的姿态，并重新采样实际动画验证目标位置；它不写一条独立的替代路线。灰色淡虚线显示修正前的真实路线，可通过“原路线对照”开关隐藏。
4. **松手只预览**。可慢放比较，按 **K** 或“应用姿态修正”才更新这个已有原帧／蓝色 K，原数量、编号和时间保留，前后两侧过渡重新生成；选 09 的任一首尾位置会同步另一端。点“取消预览 · 返回检查”或在未拖动时按 **Esc** 恢复保存动画；拖动中 Esc 只回退本次拖动。Ctrl+Z 撤销当前预览中的上一次调整。

修正只接受实际目标误差减小的候选，页面显示剩余偏差；无法到达的位置不会被显示成已到达。膝肘受两段骨长限制，通常只能改变弯向；髋与骨盆、肩与头颈有共同的联动关系。脚尖和掌心参考点分别通过脚踝、手腕解算。选中的固定手腕／掌心可移动它的支撑锚点，固定开关继续保留。想改变独立朝向、脚掌旋转或其他姿态参数，返回身体控制点调整对应保存帧。

更新某帧也会影响它另一侧的过渡，可能超出当前观察范围；完整循环可检查整圈。预览不保存，刷新会回到已保存动画。应用后复用已有原帧事务与 K 存储，支持撤销、刷新、动画 JSON 导入／导出；个人步骤和原草稿保留，不新增中间帧。进入前未按 K 的身体调整继续暂存，可从左侧“回到暂存的调整”找回。

## 整段过渡智能调整

1. 在轨迹范围选择起点／终点，例如 **09→10** 或 **09→11**，点 **生成连贯过渡 · 预览**。未选范围时使用当前位置两侧的启用保存帧。边界必须是启用的原帧或 K。
2. 在“调整这一小段”选择要处理的邻帧区间。“调整部位”可选骨盆、左右脚和非共撑手，拖场景中的彩色轴或输入厘米数值改变中间路线。共撑手保持关键姿态的支撑位置，不能作为移动路线点。
3. 从“关节弯向”选择膝或肘，调整角度；“匀速进度／平滑起停”作用于本次范围。实线是当前实际 IK 路线，灰虚线是应用前路线；不可达目标另显示淡虚线与最大偏差。拖动时间轴或慢放检查整段。普通骨骼旋转不会随采样顺序改变。
4. 松手只预览。**K／应用整段过渡** 保存整段路线参数，不新增 K 或修改两端原姿态。**取消预览／Esc** 返回保存动画，Ctrl+Z 或“撤销预览调整”回退一次临时修改。应用后用“撤销动画修改”回退，刷新与动画 JSON 备份都保留整段设置。**恢复本范围原补帧** 清除本范围路线参数。

智能调节期间，下方时间轴自动切为 **所选区间的完整宽度**，以 0–100% 检查起点到终点，显示 **区间已锁定 · 拖动不会退出**。滑动超过两端只停在边界，逐帧和标记点选不会取消编辑或清掉临时路线；边界处向外的逐帧按钮停用。播放固定循环整个选定范围，暂停后保留当前位置；范围内原帧／K 继续显示并参与原有补帧。跨圈采用连续时间，例如 16→10 显示 7–10 秒，可检查 8–9 秒尾段和下一圈的保存帧。K 端点保留精确时刻，不按毫秒网格取整。应用或取消后恢复整圈时间轴与进入前的播放范围选择；要修改起点／终点，先应用或取消当前预览。

**要把平段或折弯整理成一条圆滑弧线**，先在“调整部位”选对应的脚，再点 **重绘平滑弧线**。它以两端实际关节位置重新画一条二次曲线，拖动的点就是曲线中点；绿色轴／Y 调离地高度，X、Z 调侧摆和前后绕行。初始脚弧中点至少比两端平均高度高 8 厘米，避开此前路线贴地的低谷；仍可自由微调。**返回原路线** 取回这个部位重绘前的路线，其他部位的平滑弧线继续保留。重绘、拖动和返回都可以撤销，按 K 后才写入动画。

**要让关节绕指定球心运动**，选对应部位并点 **使用旋转中心**。场景中的该部位控制点移到中心，XYZ 和“旋转中心（球心）”数值也表示中心位置；拖中心的彩色轴就能改变整条目标路线。初始中心放在两端连线的垂直平分线上，只是可调整的种子，不是自动求出的最优动作。

“短弧 · 直接绕行”连接两端的较短转角，“长弧 · 反向绕行”向另一侧绕行。面板显示两端到中心的半径：相同时是严格的目标圆弧，不同时方向旋转的同时半径连续变化。圆心不能与端点重合，输入无效会提示并回退此次修改。“改用中点弧线”退出中心控制；“返回原路线”清除这个部位的中心和重绘模式，保留原偏移及其他部位设置。移动中心、切换绕行和模式均可撤销，松手只预览，K 应用；动画 JSON 备份、刷新和已有 K 边界继续生效。

圆心控制提供的是目标路线。固定骨长、锁手和地面仍然生效；长弧尤其可能经过地面以下或超出腿长。实线显示实际人物路线，受约束时淡虚线显示目标、面板显示偏差。可移动中心、选择短弧或配合骨盆路线调整，不能以目标圆弧光滑推断整个人物动作完美。

旧路线沿髋部旋转生成后，可能先被地面约束截平，再由路线中点偏移推移；单纯移中点会保留这个折弯。重绘直接控制曲线形状，“平滑起停”只控制播放进度。实线继续显示实际骨架，若目标受腿长、支撑或地面限制，淡虚线与偏差提示会出现：可先抬高 Y，仍受腿长限制时减小外伸，或配合骨盆路线调整。范围内保存的 K 仍是必经点；若折弯就在一个中间 K 上，需要修改它或在生成前临时跳过。

范围内每个启用原帧和 K 都是保留的边界：09→11 会保留 10，并分别调整相邻保存帧之间的过渡。生成前可勾选 **暂时跳过范围内中间 K（保留姿态）**，在预览中停止这些 K 参与补帧；范围的两端 K 和内部原帧仍保留。取消不改变原跳过状态；应用后这些中间 K 的跳过状态一起保存，随撤销恢复。K 的原姿态、编号、名称与时间位置保留，之后仍可恢复。

整段功能可用于正式循环中的其他区间、跨圈及 K→K。原始姿态 JSON、个人步骤库与草稿保留。保存记录按两端身份定向绑定；以后新增 K、跳过或删除一端使原配对不再相邻时，该路线暂不生效，记录保留。过渡调整停用时，新路线也停用；生成预览需先启用过渡调整，避免自动开启以前停用的 K。

这是一层可编辑的运动学过渡：以实际骨架为基线，在固定骨长、锁手和地面约束下重算路线、膝肘弯曲平面和肢段朝向。保存帧使用原值，内点采用可重放的扭转参数以减少轴向旋转分支导致的翻转。沿原路线的偏移在两端的位置与一阶导数均为零；重绘模式使用 `smoothPaths` 中的中点偏移，中心模式使用 `orbitPaths` 中的球心及绕行方式，均直接连接两端实际关节位置，不叠加原路线偏移。中心优先于同部位重绘曲线，旧值保留供切换与撤销。每一小段的目标曲线光滑，但受到人体可达范围及保存帧衔接影响，实际关节不保证严格圆弧、严格匀速或跨所有保存帧切线相同，也不据此宣称动作符合物理。

## 用轨迹检查相邻关键帧

没有指定观察范围时，场景显示当前两侧最近关键姿态之间的实际运动轨迹。右上“调整”中的“轨迹辅助线”可切换全关节或总开关；关闭全关节后可分别切换脚踝、膝盖与骨盆。左侧用蓝色、右侧用橙色，脚踝实线、膝盖虚线，骨盆用青色；实心圆表示起点，空心圆表示终点，箭头表示运动方向，带白心的圆跟随当前关节。左右指人物本人。可旋转视角观察路径的空间形状。

拖动下方时间轴，检查线路有没有突然折返、下坠或绕行。右侧显示当前范围的关键帧和秒数；启用的中间 K 帧参与确定范围，已跳过的帧不限制范围。恰好停在已启用的原帧或 K 帧时，一起显示它与前后邻帧之间的两段路线，便于检查衔接；首尾启用时，在编辑时间轴的 0–8 秒范围内显示可见的一侧。首尾跳过时，辅助线可连接跨循环的邻帧。

在自动相邻范围中修改身体位置或方向后，辅助线立即显示“未保存调整预览”：它预测把当前姿态按 K 保存后、两侧重新补帧的结果。更新原第 09 步时，临时预览也同步首尾姿态。按 K 后标记变为保存动画的实际轨迹，路线用于正式播放；暂存本身继续不参与播放。若停用中间修正后再新增或更新 K，预览会按保存时重新启用中间修正的行为生成。指定两个保存帧作观察范围时，身体暂存不混入真实路线；从轨迹开始的姿态修正预览会明确标注并与原路线对照。

辅助线采样与实际播放相同的保存动画、补帧速度、四肢路线、自绘脚部弧线、真实骨长、锁手和地面约束。两点之间可能有多种弧线，实线显示实际解出的脚踝轨迹；膝盖路线也会受到髋部、脚踝和弯曲方向影响。修改路线／补帧方式、保存／删除 K、更新原帧后，辅助线随结果更新。

轨迹显示偏好独立保存在 `flare-trajectory-guide-v1`，不会写入原姿态、个人步骤或动画 JSON 备份。离开动画编辑隐藏辅助线。采样只求解位置，不推进现场时间、改写骨骼或移动镜头。

## 保存、删除与备份

原姿态更新与中间关键帧保存在当前浏览器，刷新后保留。未按 K 的姿态另作暂存，可在左侧“回到暂存的调整”继续；暂存不会参与播放。在另一位置保存 K 帧不会清掉这份暂存。左侧每个中间帧右侧的 × 可以移除，“撤销动画修改”可恢复上一次原帧更新、中间帧保存／更新／删除、设置或导入；当前姿态的 Ctrl+Z 与已保存动画的撤销分别处理。刷新后仍可撤销最后一次原姿态更新，保留当前中间 K 帧；其他操作的多次撤销记录只保留在当前页面。

右侧“导出动画 JSON”同时备份当前整组固定姿态、中间帧、自绘脚部弧线、整段过渡调整、设置与暂存；“导入动画 JSON”恢复这份备份，文件需在 2 MB 以内，周期、节点数量和顺序 ID 必须相同。原姿态和过渡库一起保存，任一保存失败时尝试恢复原数据并提示错误，页面不宣称保存成功。旧版只含过渡的 JSON 仍可导入对应原姿态组。动画备份与个人步骤 JSON 分开，导入前会验证全部内容。

“路线与启用设置”中的“启用过渡调整”可停用中间修正和自绘弧线并对照旧直线版本，已更新的固定姿态仍用于播放，中间帧与弧线保留。原帧直接更新会将当前过渡帧和弧线一起保留到新姿态组，旧姿态组的过渡记录也保留；通过个人库更换正式展示时仍按原节点数据分开保存，另一组姿势的修正不会误套过来。原始导出文件、个人步骤库和原姿势草稿不由动画编辑改写。

## 当前过渡路径

默认“四肢过渡路线”采用 **沿关键姿态 · 推荐**。补帧先读取相邻保存姿态在现有骨长、锁手和地面约束下实际解出的膝肘位置及弯曲平面，再在身体局部坐标中连接这些姿态。这样两侧过渡趋近保存帧实际显示的姿势，关节接近伸直或弯向相反时不会因弯向向量抵消而突然切换备用方向。

脚部围绕运动髋部走圆弧，非支撑手臂围绕运动肩部过渡，减少端点在世界坐标中连直线造成的无意折叠；支撑手继续采用世界坐标中的保存端点和原锁定约束。鞋底需要避地时，在相同髋踝半径的地面圆周上调整。新增 K 帧保存的是编辑时实际姿势，补帧不加入仅影响显示、无法保存的临时骨骼旋转。

脚与非共撑手臂的屈曲角按两端实际保存姿态插值，再依据固定上、下骨长计算端点距离，减少近伸直姿态中直接插值距离造成的急弯。两端均锁定的支撑手保留世界坐标腕目标，肘部屈曲由现有解算器求出。采样不依赖上一帧，正播、倒拖和跳转到同一时间会得到同一姿态。

“路线与启用设置”可选择“原直线 · 对照”。已有 `arc` 过渡设置沿用推荐路线，不改保存帧的数据；`linear` 设置和停用过渡调整仍可回到旧算法。这不修改原节点或新增帧的保存值，也不替代手工 K 帧。

启用且两端相邻的自绘弧线优先指定对应脚的目标位置，其余四肢和身体继续使用所选路线算法；要检查原直线目标，可先“恢复自动路线”或停用过渡调整。弧线采用两端实际解出的脚踝位置与中点偏移，补帧参数沿用线性／平滑设置。精确原帧与 K 帧仍返回保存姿态，不以弧线覆盖端点。

补帧速度与四肢路线分别设置：“线性 · 匀速”不等于手脚必须走直线，可配合默认推荐路线；若要直线目标，另选“原直线 · 对照”。人物和手脚朝向仍用四元数最短弧旋转，骨长、锁手与地面约束继续生效，因此实际关节位移不保证严格匀速。线性模式经过关键帧时速度方向可能突变；若选错绕行或弯向，在问题区间补一个关键姿势来指定路线。
