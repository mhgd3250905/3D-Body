# 2000 · 在托马斯编辑器里切换

托马斯编辑网页顶部右侧有「托马斯 / 2000」切换（手机在「更多」菜单的「动作」里）。默认打开托马斯，点「2000」就在同一个网页里换成 Breaking 2000，预载 Pose-Hub 2000 关键帧（面向镜头起势 → 转向屈髋、右手撑地 → 后腿抡起侧翻 → 左手落地分腿倒立 → 叠手旋转 → 原路落地，42 帧）。

## 打开

- 本机：`npm run build` 后双击 `start.cmd`（或 `npm run dev`），打开 `http://127.0.0.1:8810`，点顶部「2000」。
- 切换会重新载入页面；同一个标签页刷新后仍停在 2000，新开的页面默认还是托马斯。
- 旧链接 `?move=2000` 仍然直接进入 2000（`npm run dev:2000`）。

## 用法（与托马斯完全一样）

姿势编辑、动画编辑、K 帧、左右手固定、脚不穿地、恢复原关键帧、导入／导出 JSON、复制／粘贴动画备份都照常可用。

只在 2000 下隐藏这几样托马斯专用、在 2000 下会出错的东西：「采用 v42 / R17 动作」「采用 v41 默认动作」（会把动画换成托马斯的帧）、「动画版本 · 数学轨迹试验版」和托马斯 9 步的阶段条；托马斯的平滑循环修正和教学节点也不作用于 2000。

## 分享给 Hark

动画编辑 → 「复制／粘贴动画备份」：

- **复制分享码**（2000 专有）：只带与预载关键帧不同的原帧、所有 K 帧、弧线、路线和设置，压缩成一行 `B2K1.…`，一般几千字符（完整 JSON 约 11 万字符）。点一下就复制到剪贴板，直接发给 Hark。
- **生成完整备份 → 复制 JSON**：原来的完整方式，仍然可用。
- 粘贴分享码或完整 JSON 到同一个框，点「载入这份备份」即可还原（可撤销）。
- 姿势编辑的「导出 JSON」同样可以发。

所有 2000 导出都带 `"move": "2000"`。在托马斯里粘贴 2000 的码或文件（或在 2000 里粘贴托马斯的）会被拒绝并提示先切换，不会串数据。托马斯的导出格式不变（不加字段）。分享码记着基准关键帧版本（如 `pose-hub-2000-r7`），基准不一致时拒绝还原，不会悄悄错位。

## 数据隔离

2000 下页面读写的本地存储都加 `b2000:` 前缀（`src/move-2000.js`），托马斯的个人步骤、草稿、K 帧和正式展示不会被读取或改写。

## 回到 Pose-Hub

- `tools/move-2000/from_editor.py <输入> public/coach/coach-rig.json <keys.json>`：输入可以是完整动画 JSON、正式展示、姿势库导出，或分享码（存成文本文件或直接贴在命令行）。输出 Pose-Hub 通道（pelvis、pelvisQ、spine、Wrist、Elbow、Ankle、Knee、Toe/Sole、Fing/Palm、Locked），世界坐标，旋转角已烘焙（th = 0），腿长换回 Pose-Hub 骨架。分享码按 `--base`（默认 `public/coach/move-2000-sequence.json`）还原。
- `tools/move-2000/share_code.py <分享码或文件> [--out backup.json]`：把分享码还原成完整备份 JSON。
- `tools/move-2000/to_editor.py <rN.npz> public/coach/coach-rig.json public/coach/move-2000-sequence.json`：从 Pose-Hub 逐帧结果重新生成预载关键帧。换版本后，旧版本的分享码要用旧的 sequence 文件作 `--base` 还原。
- 当前预载为 r9（`--rev r9`，起势按两条参考视频重做：面向镜头起势→转向屈髋→右手撑地→后腿抡起侧翻→左手落在右手前方→叠手旋转）；r8 版预载另存 `tools/move-2000/move-2000-sequence-r8.json`、r7 版另存 `tools/move-2000/move-2000-sequence-r7.json`，旧分享码用对应文件作 `--base` 还原。

## 检查

- `npm run verify:share`：分享码往返无损（JS 与 Python）、from_editor 两种格式输出一致、动作标识拦截。
- `npm run verify:move-switch`（先 `npm run build` + `npm start`）：默认托马斯、切换进 2000、39 帧可播、复制分享码 → 粘贴还原一致、托马斯拒绝 2000 码、新标签页仍为托马斯。

关键帧时间等距（每帧约 0.123 s，整段 4.81 s），最后一帧与第一帧同为站立；旋转段每帧身体转角 ≤ 80°，插值不会反向。
