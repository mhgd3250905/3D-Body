左边是原 v41，右边是 v42 候选，支持训练人台/卡通教练、四个视角、同步旋转、暂停看同阶段和四档周期。两边均按新候选映射到相应的原始动作阶段，便于单独判断姿态变化；这个对照不能单独证明新节奏优于旧版原生播放。预览默认 2.7 秒一圈，候选原始 clip 为 1.35 秒一圈，这是设计节奏，不是真人测量值。

## 实际修改

新增 `natural-motion.mjs`，从冻结 v41 轨迹采样，保留脚踝路线与低位支撑掌。使用现有手动双骨求解器生成另一份模型，不修改原运行时或冻结来源。

胸廓相对骨盆加入有限转向、屈伸和侧倾，头颈增加小幅独立跟随。腾空手臂按离地高度和动作阶段连续屈肘回收，再向落点伸展；初版长时间停在约 104° 的平台已修订为连续收放。低位支撑保持原腕位和手掌朝向。周期采样共享切线，最终烘焙成 22 骨、44 轨、541 帧。

两套候选直接在已验收人体 GLB 的副本中替换动画。几何、蒙皮属性和材质均读回逐项核对一致，包括训练人台已有领口修复。未重新造人体、修改固定资产或重制训练视频。

独立成品审计对每套人体采样 541 个姿态的真实掌面与鞋底、181 个姿态的完整蒙皮。近接触掌面固定小区域的水平位移最大左 1.677 mm、右 0.956 mm；包含掌面转动，不直接等同滑动。骨段长度的周期波动不超过 0.000211 mm。未发现该检查范围内的结构、地面或支撑漂移退化。

另对两套人体各 360 个相位检查手/头网格的保守局部包围盒，未发现重叠。侧面 87.5% 阶段看似贴头属于深度投影：该时刻自由手与头盒分离下界约为教练 18.92 cm、训练人台 25.90 cm。这是离散采样结果，不作为完整连续自碰撞证明。

烘焙读回的实际骨位置与生成器最大差 0.000502 mm。浏览器验证两人物切换、同阶段拖动、四档速度中的连贯/慢放播放、相机同步和 390px 窄屏；无 JS 错误、失败请求或外部网络请求，窄屏无横向溢出。最终训练人台三视角八阶段已截图复核，调整预览构图后高举脚完整显示。

`npm run build -- --outDir output/flare-v42-20261015/dist` 通过，保留原根目录 `dist`；仅有既有大 chunk 提示。这个独立目录构建用于检查原编辑器编译未受影响，不是将候选动作接入 App 的发布构建。

这次是动作设计候选，没有动捕、测力或质量分布模型，不能据此宣称“达到真人多少百分比”。真人参考支持的方向、来源及其精度限制保留在 [此前审核](flare-motion-audit-2026-10-15.md)。更大开腿幅度和更激进的身体轨迹尚未采用；当前优先修正已确认的整体僵硬与空手直杆问题。
