## 当前成果和用户目标

第一阶段托马斯姿势、动画与动态演示已由用户确认可用。第二阶段以动画为入口，让用户理解某一动作阶段的主力肌群、作用方向，并查看对应训练方法。用户要求卡通、友善、完整身体、清晰部位定位，避免暴露肌肉纤维和夸张下体轮廓。

默认动画仅显示柔和功能色区与三枚热点。悬浮速览；点击暂停在当前姿态并打开一个肌群浮窗。浮窗提供完整相关人体、局部放大、3D 全身定位图、前后视、独立旋转缩放、源肌群名称与人体本人左右，底部进入训练名称、目标、要点和步骤。一次只展开一组，避免多条引线交叉。关闭或 Esc 保持暂停，播放或定位其他时间收起浮窗。

默认静态人物是 Blender Studio Human Base Meshes v1.4.1 的 Realistic male 派生完整人体，浅色低反光皮肤、低细节人偶面部、深蓝短裤。源眼口深凹已局部闭合并省略独立眼睛，保留自然头、耳、颈、手足。Adam 作者下载需要登录，未取得该模型，不能声称用了 Adam。

亮色在静态人物自身的身体和服饰表面提示功能所在区域，深层结构另有说明；它不是实际肌肉边界、测得的肌电或肌力。真实 BodyParts3D 肌肉在详情的“解剖结构”模式中单独显示，同源体表继续保留。静态参考、解剖参考和 Snow 动作人物使用独立模型，没有精确配准。Snow 动作人物、骨架、衣服和关键姿势未替换，主动作黑短裤不参加功能着色。

## 克隆、构建和运行

验证环境为 Windows PowerShell、Node.js 24.15.0、Three.js 0.170.0、Vite 7.3.6。Vite 的 Node 要求为 `^20.19.0 || >=22.12.0`。

```powershell
git clone https://github.com/mhgd3250905/3D-Body.git
cd 3D-Body
npm ci
npm run build
npm start
```

打开 `http://127.0.0.1:8810/`，不要直接双击 `dist/index.html`。公开仓库可直接克隆；外部开发者应 Fork 后在自己的分支开发，并向本仓库的 `master` 提交 PR。第一次安装依赖需要 npm 网络或完整缓存；构建后运行只需 Node，本地模型和依赖均在 `dist`，没有 CDN。已有本机 `dist` 可双击 `start.cmd`。端口冲突用 `node tools/server.mjs --port 8811`，无需停止其他项目。

Git 包含所有运行模型、源码、工具、许可、原动画 JSON 和本交接。`node_modules`、`dist`、完整下载包、Blender 场景、`output`、个人备份目录按现有 `.gitignore` 留在本机；它们没有被删除或重置。

本地可编辑文件为 `assets/coach/flare-coach.blend`、`fitness-reference.blend` 和 `muscle-reference.blend`，不随 Git 克隆。人物改模需使用原机器的场景，或先按 [官方源资产记录](../assets/blender-studio-source/SOURCE.md) 下载并按 [人物复现文档](friendly-coach.md) 重建；单纯构建运行不需要 Blender、源 ZIP 或这些 `.blend`。
