# 手动摆放托马斯中间姿势

打开本地网页默认进入“动作分解”，暂停在你保存的第一个姿势；切换“姿势编辑”可继续调整。三维场景占据整个窗口，左上“步骤”与右上“调整”分别开关两侧栏，H 或眼睛按钮同时收起／恢复。全屏按钮进入浏览器全屏。侧栏收起时仍可以点选身体控制点、拖轴摆姿和旋转镜头；重新打开“调整”可输入数值。

左侧“正式展示姿势”使用你确认的完整循环 **9 → 10 → 11 → 12 → 13 → 14 → 15 → 16 → 9**：后双撑、左侧三个变化、前双撑、右侧三个变化、接回同一个后双撑。正式数据来自 `托马斯/16.json`，保留保存的位置、朝向和锁定状态。步骤卡片与画面字幕标注原步骤编号，最后一个 09 与起点 09 完全相同。动作分解中点击步骤会暂停在对应关键帧；在“姿势编辑”中点击步骤后可修改，保存为自己的版本。也可以拖动时间轴后点“编辑这个姿势”，从当前过渡帧继续。

展开“手脚朝向与动作要点”，查看该步的掌面和手指、脚背和鞋尖、身体节奏与对应训练。所有说明在本地离线可读，打开外部视频才需要网络。“左侧三个变化”和“右侧三个变化”沿用你的阶段命名；说明中的支撑手指人物自身，按保存的锁手状态判断：第 10–12 步右手支撑，第 14–16 步左手支撑，第 09 和 13 步双手支撑。手掌和鞋尖方向沿用你微调后的姿势。

手机上侧栏轮流显示，载入模板或自己的步骤后自动收起，以便观察全身。再点“调整”可展开数值操作。

## 调整人物

点身体上的圆点，或从右侧“调整部位”选择骨盆、躯干、腰部、左右手腕、肘、脚踝和膝，共 11 个控制点。圆点的左右以人物自身为准。

- “移动”（G）：拖动彩色轴；右侧 X/Y/Z 可用厘米微调，Y 是高度。
- “旋转”（R）：拖动旋转环，或输入角度。膝部以膝盖为轴带动小腿与鞋，肘部以肘为轴带动前臂与手掌；旋转支撑侧肘部前，先取消对应手的固定。
- “腰部”：单独调整上身弯腰、扭腰和侧弯，角度相对骨盆计算。骨盆和躯干仍负责整体位置与身体方向。
- “左手固定／右手固定”：固定相应手掌的支撑位置，再移动或转动身体。
- “脚不穿地”：约束鞋底高度。四肢长度始终保持不变，超出可达范围会限制位移。
- “撤销调整”（Ctrl+Z）：撤销一次调整；一次连续拖动算一次。“看全身”重新对齐镜头，“从站姿开始”重设起点。

拖动控制轴时镜头保持固定。拖动空白处旋转观察、滚轮缩放。控制点与固定长度约束帮助摆姿，姿势是否符合你的托马斯标准由你判断。

选中部位后，右侧显示对应的操作说明。膝和肘保留原有移动方式，也可以直接旋转。腰部转动时，未固定的手臂随上身移动；固定的手掌保留支撑位置，继续遵守原有骨长与可达范围约束。

## 保存中间步骤

摆好后输入步骤名称，点“保存新步骤”。左侧“我的托马斯步骤”按顺序保存姿势；点击步骤载入，修改后点“更新此步骤”。上下箭头调整顺序，移除后可用“撤销移除步骤”恢复。个人步骤与正式展示分别存放，载入展示姿势不会删除已有步骤。

当前草稿和步骤保存在这个浏览器的本地存储中，关闭网页再打开可继续编辑。“导出 JSON”保存全部步骤；尚无步骤时保存当前姿势。“导入 JSON”将文件中的步骤追加到列表。更换浏览器或清理浏览器数据前，可用 JSON 备份。右上角“保存视图”导出人物 PNG，自动隐藏控制点和旋转环。

## 将微调用于正式展示

本次更新会把旧正式展示升级为项目中的 9–16–9 循环，旧版另行备份，个人步骤和当前草稿不改写。撤销升级后再刷新，会保留你恢复的旧展示。

在“我的托马斯步骤”保留当前 16 步或更多步骤后，点击“用于正式展示”，会优先按原步骤 ID 找到第 9–16 步，缺少匹配 ID 时使用列表第 9–16 项，再追加同一个第 9 步闭环；额外第 17 步不参与本循环。以后继续修改步骤，先点“更新此步骤”，再点“用于正式展示”同步新的保存值。仅有完整九步的个人库仍可以按九步列表发布。正式替换保存于独立的本地存储键，刷新后保留；“撤销展示替换”恢复上一次展示，个人步骤仍可继续编辑。

## 按自己调整的半圈补齐镜像

前五步已经调整为前双撑 → 右侧移重 → 右侧单撑 → 换腿回撑 → 后双撑时，在“我的托马斯步骤”下面点击“补齐另一侧”。从后双撑继续，按第 4、3、2、1 步的镜像追加为第 6–9 步；第 9 步接回前撑。原来的五步保留。追加的是你实际保存的数据，预设模板没有参与重建。

本次更新在原浏览器打开时，若恰好保存了按上述五个模板顺序调整的五步，会自动补齐一次；其他步骤库由按钮操作。主动撤销后，再次刷新不会自动重新补齐。

镜像沿人物模型 X=0 的矢状面完成，左右手脚整组交换，骨盆、躯干方向、手腕、肘部、脚踝、膝部弯曲方向、掌面、鞋尖与支撑手一起镜像；地面锁定保持原值。侧栏说明和推荐镜头也随左右交换。镜像后的步骤可以载入并继续优化，更新镜像不会修改其原姿势。

补齐前会在同一浏览器保存一份完整的本地备份。“撤销补齐”移除本次追加的步骤，仍可逐个恢复；已经生成的镜像不会重复追加。若需要更换浏览器，请在原浏览器导出 JSON，导入时保留镜像说明。

## 实现和验证

人物使用 Snow 来源的真实蒙皮网格和 20 根整理后的网页骨骼。`src/coach-motion.js` 以固定长度的双段 IK 驱动四肢，处理身体旋转、手掌支撑和鞋底高度；`src/pose-presets.js` 读取 9 个原始关键姿势并附加教学说明；`src/flare-sequence.js` 提供 9 秒位置与最短四元数插值；`src/official-poses.js` 管理正式展示及独立备份；`src/pose-editor.js` 用 Three.js TransformControls 提供三维拖动；`src/pose-panel.js` 管理微调、撤销和 JSON 步骤库；`src/workspace.js` 管理侧栏和全屏，镜头避开已打开的桌面侧栏。姿势只控制运动人物，详细肌群仍使用独立解剖视图。

姿势文件格式为 `flare-pose-library`、版本 1，包含命名步骤、骨盆位置、躯干四元数、四肢端点及弯曲方向、手足旋转和锁定开关。独立腰部方向保存在可选 `torsoQuaternion`（相对身体方向），肘和膝的轴向扭转保存在可选 `elbowTwist` / `kneeTwist`（弧度）。旧文件缺省这些字段时保持原姿势，保存、镜像、展示插值均支持新字段。导入时先验证全部姿势，无效文件不会部分写入已有步骤。

```powershell
npm run build
npm run verify:presets
npm run verify:sequence
npm run verify:official
npm run verify:demonstration
npm run verify:motion
```

本次按快速开发要求，只检查新九帧与保存来源逐项一致、精确闭环、骨长与支撑漂移、缓存升级与撤销、个人数据保留，并构建和确认浏览器展示。新记录位于 `output/official-loop-9-16/`。上述全量复核命令和 `output/official-sequence/`、`output/flare-sequence/`、`output/pose-presets/` 记录属于此前版本的检查，本次没有重跑全量测试。连续过渡仍遵循原有 IK 可达性约束，整数关键姿势保留用户原值。
