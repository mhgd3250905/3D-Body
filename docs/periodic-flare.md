在“动作分解”右侧打开“调整”，把“动画版本”改为 **数学轨迹 · 试验版**，点击播放或拖动时间轴查看。切回 **你的保存动画** 可在同一机位、同一时间对比。当前沿用 9 秒慢放周期，整圈持续运动，8–9 秒也会接续摆腿。

试验使用现有 Snow 人物、原始网格和蒙皮，没有替换模型。它独立于原第 09–16 步和中间 K 帧，不要求逐帧调整。切换、播放和刷新不改写正式姿态、个人步骤、个人草稿或过渡库；刷新回到保存动画，进入姿势／动画编辑也先回到保存序列。原动画的固定帧更新、K 帧、撤销与备份入口继续适用。

## 当前生成方式

2026-10-06 用户试用后认为动画效果不理想，当前回到原关键姿态与手工 K 帧，并用保存动画的实际轨迹辅助调整。数学方案作为独立试验保留，下面的数值检查只说明相应约束通过，不能替代动作效果验收。

实现位于 `src/periodic-flare.js`，通过 `src/coach-motion.js` 驱动真实骨架。以相位 θ = 2π · frac(t / T) 统一描述骨盆、身体倾转、两腿摆动与换手。它从周期函数生成整圈目标，再求解关节；不把存在幅度差异的原节点当作必须经过的位置。

骨盆水平轨迹为椭圆：x = 0.22 sin θ，z = 0.06 − 0.34 cos θ，单位米。身体方向由归一化四元数谐波曲线控制；骨盆高度取双臂实际可达高度的平滑交集，留出小幅屈肘，避免用硬截断或上一帧修正来保持手掌。

双腿在身体局部坐标中生成，左右开腿角分别为 48° ± 36° sin θ，屈髋角为 50° + 25° cos θ + 30° cos 2θ。方向为 (±sin α, −cos α cos β, cos α sin β)，再随身体旋转。左右按反向相位镜像，交替抬高和低位扫腿；两脚在世界坐标中各完成一圈，而不是始终隔着 180°。

踝到髋的半径由原始大腿、小腿长度和 8° 膝屈确定：r² = a² + b² + 2ab cos 8°。低位需要避地时，根据实际旋转鞋盒的平滑上界抬高方向，并重新归一化水平分量，保留半径；不拉长腿。实际双骨 IK 保留各段骨长，膝部弯向沿身体前方，肘部使用稳定的外后方引导。数学播放的骨骼旋转同时对齐肢段轴和弯曲平面，减少仅按轴对齐接近反向时的急拧；手动姿态和保存动画继续使用原朝向规则。

支撑时长是这次试验的设定：后双撑 14%、右单撑 35%、前双撑 16%、左单撑 35%。支撑手的腕位置、掌方向在整段接地期固定；腾空手使用 64u³(1−u)³ 的抬手曲线，其位置、速度和加速度在起落端与接地状态接合。至少一只手始终标记为支撑。这些参数是针对当前模型的动作设计，不是专业选手的测量标准。

脚的实际曲线由身体旋转、髋角、固定腿长和避地共同决定，并非严格斜椭圆。当前没有求解接触力、惯性或真实重心动力学，也没有用动作捕捉校准；数学闭环和数值连续不等于动作完美。脚仍受关节控制，回落不能直接当作独立自由落体。

## 依据与边界

[2009 年地面／鞍马并腿全旋研究](https://ojs.ub.uni-konstanz.de/cpa/article/view/3328/3128) 将周期划分为前后双撑和左右单撑，地面样本的单撑明显长于双撑。它仅研究两名选手的并腿全旋，不能直接给出地面分腿托马斯的统一参数；这里只参考其支撑阶段关系。

[2024 年单手支撑旋回理论模型](https://pmc.ncbi.nlm.nih.gov/articles/PMC11380692/) 联合描述身体倾转、绕行和轴向旋转，支持把周期旋回建模为协调运动。其刚体、并腿和支撑假设不直接验证本项目的分腿动作。[教练 Flare 示范](https://breakdancingninja.com/proto/how-to-flare/) 也强调两腿不同的踢起时机。上述资料帮助选择结构，当前参数仍需通过实际播放反馈优化。

## 验证与复现

```powershell
npm run build
node tools/verify-periodic-motion.mjs
node tools/verify-periodic-ui.mjs
```

第一项骨架检查加载实际 Snow GLB：720 个周期区间、20 根骨骼，覆盖固定骨长、鞋底高度、支撑腕／掌跨帧固定、跳转与倒拖确定性、首尾闭合，以及循环和四个换手边界的位置／SO(3) 角速度连续性。还检查切回保存动画后九个原姿态及骨骼朝向保持兼容。

浏览器检查要求 8810 本地服务、本机 Chrome 与已有 bundled Playwright，使用独立浏览器上下文。覆盖版本切换、原位对比、播放、个人草稿恢复、原帧与 K 帧保留、刷新、手机布局，以及已发起的导入在切换数学模式后延迟完成的状态一致性。它不改用户当前浏览器数据。

2026-10-06 本轮定向检查：骨架 10 组、浏览器 14 项均通过，浏览器错误为 0；原固定帧更新回归 27 项、正式循环纯模块 21 项也通过。16 个实际人物画面用于整圈视觉检查。另对 49 个蒙皮姿态约 1,034 万顶点做本地抽样，未发现低于 y=0 的顶点；该抽样不保证所有时刻没有自相交。报告和截图保存在被 Git 忽略的 `output/periodic-analysis/`，当前动作自然度仍待用户试用。
