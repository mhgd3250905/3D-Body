## 目录职责

- `lib/domain/`：纯领域数据、剂量、计时和测评规则，使用可注入时钟；不依赖3D帧循环。
- `lib/data/`：内容加载与本地存储边界；源字段、未知旧字段及损坏数据需保留可追溯性。
- `lib/control/`：学习状态与页面所需的控制器；训练记录不自动代表课程或关卡通过。
- `lib/ui/`：Flutter 页面、导航与交互；文案修改从 `lib/l10n/` 的 ARB 源进行，不手改生成翻译文件。
- `lib/platform/scene/`：Web/native桥接、命令队列、生命周期和本机资产服务。
- `scene/src/`：局部3D渲染适配；`scene/src/legacy/` 为制作包原样副本，哈希清单在 `scene/tools/source-manifest.json`。
- `assets/scene/`：生成物，修改场景后从 `scene/` 构建；`assets/data/source-manifest.json` 记录内容与图像来源。

并行子任务按独立目录约定所有权，避免交叉覆盖；主 Agent 整合接口、结果和验证。

## 资产与行为

坚持零预算、离线、无 CDN。使用成熟自然人体，不制作球体/圆柱拼接的人物替代正式模型；禁止付费模型、插件或收费生成服务。保留 Snow 署名、原网格、原始导出与个人草稿；不覆盖根目录旧网页、`Air-Flare/` 或 `E:\AII-3D\3D-Wrist`。

当前动作使用 v42-R12 烘焙 GLB 与 AnimationMixer，保留原步骤09–16接回09的教学语义，时间与姿态由场景核心统一拥有。Flutter序列时间为0–9，内部通过非线性时钟映射到1.35秒片段，默认0.5倍一圈2.7秒；不重复安装辅助骨，不叠加 IK 或 paced clock。v33/v38源码、动画、清单保留历史基线，当前来源为 `scene/tools/v42-r12-source-manifest.json`，接口/外观以 `docs/motion-v42.md` 为准。动作优化同步网页与App，须有来源、备份与复测；不能把历史验证当作新版通过结果。模型优化使用派生副本，记录输入/输出哈希并验证骨骼、蒙皮与轨道，未经验证的减面结果不进入默认人物。

首页和指定肌群详情使用设置保存的七种形象；五种新风格是原卡通教练或领口修复训练人台的材质与头饰派生，既有身体保持并统一播放R12着装动作。详情仅当前肌群柔边代理高亮、打开时推荐全身机位，允许旋转但禁止缩放和平移，不着色脸、头发、手和鞋；独立直立人台显示精细分区线、当前选区及淡影。点小卡片交换大小，同一暂停帧、群组与返回保持；返回恢复角色材质对象。历史米白无衣派生模型、交接和截图保留，不加载到当前正式场景，也不改写历史验证。

播放显示克制轨迹特效，不展示教学点选标签；暂停、选择肌群或进入详情时特效淡出，暂停才显示点选信息。系统减少动态效果下也必须完成淡出。肌群颜色是教学位置/功能关联，不是肌电或发力百分比；深层位置标示意，不制造缺失真实解剖网格，不声称人物精确配准。课程与测评保留草稿/自评说明，免费开发版不放假 Pro 锁或假 AI 分数。

## 必要验证

检查与修改成比例：运行受影响的 `flutter test`、`flutter analyze`，必要时构建并在浏览器核对布局/流程。场景变化运行 `npm run build` 和 `npm run verify`；Web交付构建使用 `flutter build web --no-web-resources-cdn`。通过后停止重复扩大测试，不默认运行根目录旧编辑器全量检查。

来源/动作改变时需重新核对硬规则、阶段时长和同帧返回；平台变化需取得对应设备证据。更新 `docs/verification.md` 中的命令、时间、结果及限制，缺设备或外部审核就明确待验证。

只读与可逆开发直接进行。生产包标识、签名和不可逆外部发布在结果可审阅后按用户授权处理；不自动上传、公开部署或推送。常规缺口自行处理，只有会实质改变结果的信息才询问，并继续不依赖答案的工作。
