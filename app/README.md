## AI 定制（当前 SDK 0.4.1）

计划页顶部「AI 定制」支持描述需求、独立问题气泡与多轮补充，计划卡可「保存到我的计划」或「开始训练」。当前共用 SDK [ugk_coach](https://github.com/mhgd3250905/ugk-3d-pose-sdk) 为 **0.4.1**，`ugk_trainer` 为 **0.2.0**，两个 git ref 均固定到 `8b60032c2f43fd8e91f8802c8f054a8ecb7cc110`；与 `pubspec.yaml` / lock 一致。当前完整计划播放器及分段剂量接入见 [SDK 0.2 记录](docs/sdk-trainer-020-2026-10-23.md)，原 [PR122 合入记录](docs/pr122-ai-coach-integration-2026-10-20.md) 保留历史。

## 当前体验

首页沿用制作包 v2 的 `h1-home` 布局：顶部为计划与更多入口，主要区域是完整人物，左下同步肌群小图，底部只保留播放/暂停和细时间轴。没有常驻底部导航、速度排、镜头排或肌群标签排；这些功能移入更多或暂停后的点选。详见 [首页视觉基准](docs/home-design.md)。

启动页下方实际预加载同一3D场景，以真实Flare动作剪影等待人物和小图首帧绘制完成，再连续揭开界面。首次进入需确认安全须知，然后进入动作观看；慢放、暂停、阶段定位、单段循环与镜头控制保持。

暂停时最多3项重点肌群与左下人体图一致，圆点始终可见，同色卡片通过细引导线定位发力点；双侧肌群随旋转优先选方便展示的一侧，卡片避开身体并平滑移动，地面与画面边界保护保持。点人物热点、小图或肌群弹层可进入当前姿态的肌群详情。首页与详情跟随设置保存的七种形象，五种新风格只替换底模材质并加头饰，统一播放同源R17烘焙动画；详情只对当前群组柔边高亮，推荐全身取景，可旋转但禁止缩放和平移，脸、头发、手和鞋不着色，返回恢复角色材质对象。播放显示克制轨迹特效，暂停、选择肌群或进入详情时淡出，教学标签仍只在暂停时展示。

详情默认大动作模特、小直立肌群人台。小卡独立高清采样并完整展示全身，人台保留精细分界线及当前选区，其余阶段色收起。点小卡交换两者再切回，部位和暂停时刻保持一致；动作表面色区与静态人台均是教学位置提示，不宣称精确解剖配准。

主力列表、其他参与及详情协同肌群条目使用17张离线拍摄的银色人台图，每张以合适镜头高亮对应肌群；这项外观已获用户确认。训练按无器械、居家、健身房三种场景与部位/搜索联合筛选；51项动作展示采用源视频封面与可点播卡片，旧示意图保留历史，要点、组次与安全说明继续使用。计划页提供6套训练方向及可命名、排序、复用的个人计划；跳过按顺序前进，末项后结束本轮，分别显示完成与跳过。结束后可点选补练或重练。

全部训练档位按免费开发版提供。个人计划、训练会话与进度存在本机；原课程、自评、关卡与今日清单的数据及 Store 接口保留，相关旧界面已由计划替代。原教学草稿未因本轮更改完成教练审核。当前没有相机 AI、订阅、账号或云同步。颜色表示教学重点，深层位置为示意，不能当作肌电、内部解剖边界或能力诊断。旧训练图片的姿势瑕疵保留历史记录；新视频的源QA限制见媒体清单。

设置中的“复制本地备份”把部分状态复制为 JSON，需自行保存到文件；当前没有备份导入入口，它还不是完整的迁移方案。
