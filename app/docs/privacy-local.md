# 当前实现的本地数据说明

本开发版没有账号、订阅、云同步、埋点或崩溃上报服务。模型、动作、肌群数据、训练图与字体由 App 安装包提供；当前没有相机 AI，也不请求相机权限。本文件说明当前代码的行为，不替代以后发布所需的正式隐私条款。

## 保存什么

`LearningStore` 将 JSON 写入本机 SharedPreferences，版本键为 `flare.learning.v1`。内容包括安全确认、训练档位/速度/提示偏好/周目标、上次动作时间、今日训练列表、训练会话、课程完成记录、本人确认的关卡和五项入门自评。训练会话记录动作、时间、有效练习秒数、完成/计划组数、完成状态和本人触发的疼痛标记；这些是学习记录，不是 AI、能力或健康诊断。

浏览器预览保存在当前浏览器与网址对应的存储中，更换端口或浏览器会进入另一个存储范围。原生数据在 App 自己的存储范围内。当前未提供 App 级加密、跨设备迁移或云端恢复功能。

读取失败或状态损坏时，存储层阻止自动覆盖原数据并提示问题。播放器保存时刻按暂停、导航等节点进行，GPU帧和相机操作不会每帧写入持久化。

## 本机 3D 通信

Android/iOS 在设备内启动仅绑定 `127.0.0.1` 的临时 HTTP 服务，为 WebView 提供 bundle manifest 白名单中的场景资产。路径不能越出白名单，服务不公开本机目录；WebView 导航限定当前本机来源，离开视图时关闭服务。该服务用于本地模块和 GLB，不向远程服务器发送训练记录。

Android 的 `INTERNET` 权限是访问 loopback 所需的系统权限；它本身不代表系统仅允许 localhost。当前代码只访问本地场景，明文 HTTP 例外仅配置给 localhost/127.0.0.1。iOS 使用 `NSAllowsLocalNetworking`。Web 使用同源 iframe，并同时检查消息窗口与来源。

App 或浏览器进入后台时，动画暂停，保留当前时间；训练计时也暂停，返回后由本人继续，后台等待不会自动算作完成练习。

## 备份与删除的现状

设置中的“复制本地备份”导出 `flare.local.backup.v1` JSON 到系统剪贴板。当前字段为安全确认、设置、动作时间、今日训练、训练会话、课程完成ID、关卡、自评与导出时间；没有全部内部状态、导入入口或恢复验收。请将复制内容自行保存为文件，不把该按钮视作完整备份/迁移保障。剪贴板和自行保存文件由操作系统与用户管理。

当前没有“删除本机数据”的 App 内入口，也没有备份导入；它们属于 M5 后续工作。卸载原生 App、清理浏览器站点存储或重装前，应先保留想要的记录。以后加入 AI、购买或联网功能时，需要先明确实际数据流、权限和用户选择，再更新本说明与正式隐私文案。
