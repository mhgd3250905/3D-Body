# v41：网页与 Flutter App 同步动作

2026-10-09 用户要求将 PR #3 的动作优化接入 App，并明确网页和 App 的动作应一起同步。当前默认版本统一为 v41；网页保留原姿势/动画编辑器，App 保留 PR #2 精简界面、深浅主题、穿衣详情柔边代理高亮及固定动作机位。v38、原始导出、白膜派生资产和历史截图不删除。

## 固定来源与改动

来源为 `mhgd3250905/3D-Body` 的 PR #3，固定提交 `53d72b412840a942fefc818836b68ad2a2d7e0d1`。动作修正提交 `3e46a33` 限制脚掌绕腿轴的扭转及翻转，同时保留勾脚；模型修正 `c2f4a13` 协调领口与颈部皮肤的蒙皮权重。没有换脸，没有采用已弃用的 v39/v40 动作。

成熟 Snow 网格、材料、位置、法线、UV、索引和逆绑定保持原来源；领口/袖口附近的局部蒙皮有意变化。源 GLB 为7,508,016字节，SHA-256 `c14683e4ffa8ebbb3e6712af8e04ee3276059398cec03b1192d5b67c179b858f`。来源和派生文件逐项哈希见 `scene/tools/v41-source-manifest.json`，v33/v38 清单仍保留。Snow 的 CC BY 4.0 署名随包提供，费用为0元，没有收费生成、购买或 CDN。

## App 播放与复现

`scene/source/v41-runtime/` 保存来源提交的独立只读模块副本。`node scene/tools/bake-v41-node.mjs` 在纯 Node/Three.js 中按来源运行时和 paced clock 采集，再导出 `flare_v41_loop`；`node scene/tools/optimize-v41.mjs` 无损 meshopt + gzip。可复现工具、源时钟、阶段与模型都在本地，不依赖远程服务。

源烘焙 GLB 为7,989,300字节，运行副本2,614,855字节；22骨、44轨道、540帧（539个独立帧及重复首帧）。1倍一圈8.991662288秒，0.5倍约17.9833秒。Flutter 继续使用0–9秒序列域，播放器通过逐帧时钟映射到已烘焙动画，速度只应用一次，不在 App 再运行 IK、辅助骨安装或节奏积分。当前阶段、高亮、单段循环与暂停帧按同一映射更新。

GLTFExporter 在烘焙导出时会归一化源法线；后续压缩的“无损”指相对于已导出的烘焙 GLB，不声称导出前每个源法线分量原样不变。

## 网页编辑与个人数据

网页采用同一来源的 v41 运行时、正式九步和领口模型，仅同步动作相关模块与时钟，不套用 PR #3 的整套网页界面。原动作模型/JSON 备份在 `public/coach/flare-coach-before-web-v41.glb` 与 `flare-sequence-before-web-v41.json`。

默认内置循环升级到 v41；已有个人发布的正式动画、K、路线、姿势库和草稿保留自己的来源。两端一致性验证针对当前内置默认循环，个人旧动画不冒称为 v41。迁移和切换入口的备份行为见 [网页来源清单](../../public/coach/motion-v41-web-manifest.json) 和 [实际验证工具](../../tools/verify-web-motion-v41.mjs)。

“采用 v41 默认动作”先独立备份正式选择、撤销槽和K/路线库原字节，再切换默认；备份失败拒绝替换，不清个人数据。个人新K/路线或线性插值按编辑后的序列播放，不冒称与默认烘焙片段一致。

## 验证范围

纯 Node 烘焙540帧逐帧骨/身体皮肤对照：骨最大0.000533毫米、皮肤最大0.000566毫米；24个帧间采样最大骨差0.230843毫米、皮肤差0.236219毫米；首尾骨差0。原样哈希、无损编码和当前136个肌群/阶段案例由 `app/tools/verify-v41.mjs` 检查。

`node tools/verify-web-app-v41.mjs` 另用实际安装的根网页代码与 App AnimationMixer 对照540帧，而不是仅对照来源镜像。已测骨位置最大差0.000533毫米、旋转最大差8.27e-7弧度、时钟正反转换差0。`node app/scene/tools/verify-framing.mjs` 检查当前390×650构图的181姿态，每8顶点采样的投影范围为[12.05,53.08]至[360.99,371.56]。

这些数值验证动画与软件转换，不表示人物和解剖精确配准，也不表示真机帧率或医学精度。最终构建和浏览器证据见 [verification.md](verification.md)；≥45fps、手机温度/内存及原生设备验收继续待真实证据。

来源v41的逐帧脚部高度指标最低约−8.66毫米；关闭新脚踝修正后也有同类现象，未归为此次新增回归。本轮未自行改高用户认可的动作，不宣称完成全身/地面碰撞检验。
