# 国际化

L38 将界面与学习内容的 14 种语言资源随 App 离线打包。语言选择、界面文案和学习目录分别维护：Flutter 界面文案使用 ARB，动作和课程目录使用源字符串映射表。

## 支持语言与选择

支持 `zh`、`zh_Hant`、`en`、`es`、`pt`、`fr`、`de`、`it`、`ru`、`ja`、`ko`、`ar`、`hi` 和 `id`。语言选择器从 [languages.dart](../lib/l10n/languages.dart) 读取各语言的本地名称。

默认 `system` 跟随设备语言偏好列表，选择列表中第一个受支持的语言；没有匹配项时使用英语。系统语言为繁体脚本 `Hant`，或设备地区为 `TW`、`HK`、`MO` 时使用繁体中文 `zh_Hant`；其他中文地区使用简体中文 `zh`。手动选择保存在 App 本机学习设置中，重启后保留；重新选择“跟随系统”即可恢复设备语言。

## 界面文案

[app_zh.arb](../lib/l10n/app_zh.arb) 是模板。14 份 `app_<locale>.arb` 均包含相同的 270 个用户可见键、对应的 `@@locale`，以及模板中的 `@` 元数据。编辑翻译时保持占位符名称、类型和 ICU 结构一致。自行回顾阶段和腕屈/腕伸的 4 个领域文案也由 ARB 提供，应与其他界面文案一起维护。

`app_localizations*.dart` 是生成文件。修改 ARB 后重新生成，不要直接编辑生成代码。

## 学习内容

[content_zh.json](../assets/l10n/content_zh.json) 提供 591 个精确的源字符串键。各 `content_<locale>.json` 必须保留相同键集，并翻译对应的显示值。字典涵盖 17 项肌群说明、动作阶段及教学说明、51 张动作卡片，以及课程草稿和课时。保持内容 ID、图片路径、阶段引用等源标识不变，只翻译显示文字。

[content_translations.dart](../lib/data/content_translations.dart) 从 App 内打包的 JSON 加载翻译。[Catalog.localized](../lib/data/catalog.dart) 在中文源目录完成解析后创建用于展示的副本，不改变 ID、剂量结构、数字目标和来源引用。训练记录仍使用这些稳定 ID，不因切换语言而改写。剂量单位、次数、时长及左右侧说明须与源内容等义；英语内容文件也必须保留完整的同一键集。

翻译须保留源文的限制与状态：课程仍是供个人回顾的草稿，训练说明仍是参考信息，不得暗示内容经过医疗审查、构成处方或具有未经证实的安全保证。图片瑕疵说明、本机存储和离线使用说明也须准确。

## 紧凑显示名（L39）

14份 `muscle_short_<locale>.json` 用17个稳定groupId维护准确短名，与完整591内容映射分开。Flutter与场景共用短名，窄标签/标题/卡片/练习按钮显示；说明、搜索索引和读屏保留完整名称，训练跳转预填短名，全名仍可检索。规则与英文逐项依据见[compact-labels.md](compact-labels.md)。首页提示采用短句，阶段名允许两行；不可直接切掉词尾或用省略号冒充翻译。新增短名须同步14语言并检查每语言唯一。

## 场景与字体

Flutter 将本地化的肌群名称、无障碍文字、语言区域和文字方向发送给 3D 场景。场景更新文字方向与画布标签，并从 App 内加载对应字体。该本地化命令只改变显示文字和方向，不会镜像 3D 人物，也不会重置动作时间。

`FlareSans` 覆盖拉丁字母、西里尔字母、日文和繁体中文字符；随包提供的 `NotoSansKR`、`NotoSansArabic`、`NotoSansDevanagari` 分别补充韩文、阿拉伯文和天城文字符。阿拉伯语使用从右至左的文字方向。字体与 SIL Open Font License 文本均随 App 打包；运行时不使用 CDN，也不下载翻译或字体。

## 翻译维护与检查

变更源字符串时，更新中文源和所有语言字典，使源键集合完全一致。界面文案在模板及全部语言 ARB 中同步维护，并保留元数据和占位符。内容含义以中文源为准，英语可用于交叉审阅，不能代替核对中文源文。

在 `app/` 目录运行以下命令，重新生成界面本地化代码并检查资源结构和数字 token：

```powershell
flutter gen-l10n
python tools/verify-localization.py
```

检查脚本会核对 14 个 locale 的键覆盖、`@@locale`、界面占位符、内容非空值和内容数字 token 顺序，以及14×17短名覆盖、唯一和无省略号。这些检查能发现结构或剂量数字漂移，但不代表母语表达质量或医疗准确性。L38 翻译由 GPT-6 Luna max 完成，并经过结构、数字、字体 cmap 检查和英语交叉审阅；未经过母语者或医疗人员审核。当前测试、浏览器和安装包证据以[验证记录](verification.md)和[版本台账](version-ledger.md)为准；通过源文件检查不等于完成真机或发布验收。

## 平台边界

Android声明 `supportsRtl`；iOS Info.plist声明14种语言，plist已解析核对，但本机Windows未构建iOS。语言偏好由App持久化管理，未接入Android/iOS系统单独App语言同步接口。L38的33项、L39的12项为各阶段历史回归；L43与本次收束的定向回归、14语两宽度及限定浏览器证据见[verification.md](verification.md)，原生设备/读屏与母语审阅仍待验收。
