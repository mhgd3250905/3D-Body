# 角度训练计划审计（21套，覆盖8角度）

日期：2026-11-17。只读来源：`feat/flare-plans-full @ b461a0d`，`feat/flare-plans-full @ b461a0d887737a73d7aeda50b3fcb4ee53323c75`。审阅 `flare-plans.json`、248项目录的动作说明/节奏/器械、`training_plan_adapter.dart`。本报告没有修改产品代码或媒体。角度15镜像使用角度11的三档，并非缺了三套。

## 结论与优先级

目前选的肌群与动作总体有基础训练价值，但不能把这些组合直接称为已验证的托马斯专项处方。主要问题是：初级的支撑要求和总量偏高；高级堆叠多个相近的高难支撑；换腿/移重角度缺少真正的阶段衔接；器械替换保留原剂量后改变了动作意义。先修正剂量语义，再调整处方，比先制作更多动作更重要。

下文精确组次和替换顺序均是**教练式设计建议/待试练的起始剂量**，不是临床处方，也不是针对托马斯的直接实验结论。适用于无当前疼痛、已具基本运动能力的成人；等级应按完成质量决定，不只看“初级/高级”名字。

### A. 可以直接定位的配置问题

1. **静态支撑换成动态动作却沿用秒数。** `training_plan_adapter.dart:143–185` 保留原 sets/reps/seconds/perSide；遇到计次动作承接秒数，又覆盖成 `kind: hold`。例如 angle-11-t2 的 `triceps-B` 4×15秒 → `triceps-A`，angle-11-t3 的4×20秒 → `h-pike-pushup`；angle-12-t2 的 `triceps-B` 3×20秒 → `triceps-A`、`abs-B` 4×10秒 → `lats-A`；angle-12-t2/t3 的 `adductors-B` 3×20/30秒 → `h-inner-thigh`。这不能视为已经设计好的等价替代。后者有无保持、保持在哪、是否还按动画计次都必须明确。建议替换项独立拥有模式、剂量、侧别和节奏；动态内侧抬腿采用2–3×10–15次/侧，窄距或跪姿俯卧撑采用2–3×6–10次，而不是自动继承20秒。
2. **“徒手”仍要求弹力带/哑铃。** angle-11-t1 的 `hip-abductors-B` 没有替换；angle-11-t3 的 `deltoids-B`、`rotator-cuff-B` 没有替换。`flare_plan.dart:86–87` 对 A 只取 bodyweight 或原动作，B/C 都取原动作。因此“居家”也没有根据双杠/吊环/器械可用性重新选动作。椅子、墙属于可用环境还是器械，应单独说明；至少弹力带、哑铃不能算无器械。
3. **实际分侧错配与已核实的交替计数。** angle-9-t2、angle-13-t1：双侧 `hip-abductors-B` → 分侧 `w-clamshell` 仍继承 `perSide=false`，应单独安排两侧；angle-12-t2：双腿同时抬的 `hip-flexors-A` 却为 true，应取消分侧。另一方面，`rotator-cuff-A`、`chest-A`、`obliques-A`、`h-mountain-climber`、`h-bridge-march`、`t-seated-straddle-lift-1leg` 的目录明确是 `rep_alternate` / `repUnit=left+right`。**执行审计已核实 SDK `session.dart:442` 通过 `!rhythm.alternatePair` 排除再次分侧，因此计划中的 perSide=true 不会让这些动作执行两遍，不属于执行错误。** 对它们仅建议把界面与口令统一为“左+右各一次算1轮”；不要机械地改变 perSide。`h-russian-twist` false本身也不算错误，它同样按左右一轮计数。
4. **“专项动作”名称不能替代动作理解。** `t-flare-side-hold` 的目录说明是下面的手和脚支撑，属于脚辅助侧撑；不是全悬空托马斯定格。`triceps-B` 的平行杆直臂支撑与派克俯卧撑在方向、关节动作及负荷上不同；`abs-B` 团身L撑与仰卧 `abs-A` 空心体也仅保留部分躯干要求，不能声称等价。

### B. 处方结构问题

初级11现有侧平板、直臂沉髋、触肩、窄距俯卧撑连续四项支撑；即使不谈风险，也把真正的新手挡在入口之外。高级9同一天放宽腿L撑、L撑开合、分腿支撑、双杠臂屈伸、L到V画圈，优先目标模糊，最后的复杂动作只能在疲劳后练。高级10/14把团身俄挺作为默认门槛，专项收益不足以支持所有用户必做。12、16作为换腿课，大量普通髋/躯干训练仍不能覆盖手落地时机、腿的空间路径和连续过渡。

## 建议剂量与计数约定

每堂先做3–5分钟渐进热身：轻活动、肩胛控制、手腕在舒适范围逐步承重。现有 `forearms-A` 可保留为其中一项，但不是让每个人强行完成所有极限腕位。执行审计已核实其60秒拆成四方向各15秒，属于定时自由摇摆，并非让视频静止或等长保持；只需把口令统一成时间内缓慢摇摆，说明与目录定次数不同。以下表格不再重复热身。

- `组×次`为动态动作；标“轮”表示左+右完成后才记1次，计划不应再重复分侧。“/侧”表示左、右独立完成。`t-seated-straddle-lift-1leg`虽然名为单腿抬起，现库却按左右成对计数，下面一律写“轮”；6轮即每侧各6次，而不是左右各再做6轮。
- 技术/难支撑置前，常从3组×5–10秒或3组×3–5次起步，组间90–150秒；特别困难可休到180秒。一般力量2–3组×6–12次，休60–90秒。轻辅助2组×10–15次，休45–60秒。表内另有说明时优先表内。
- 保留约2–3次动作余量；技术姿态失真即结束该组。等长停留以能稳定呼吸和保持目标位置为前提，不追求最长时间。先稳定完成，再小幅加次数/秒数，最后改杠杆/支撑条件；不要同时提高所有变量。
- 初级、中级、高级是三种可选入口，不是一天串练三套。每次选1个主要角度，必要时加1个弱项；每周2–3次力量/专项课是可试行起点，结合其它训练核算肩腕负担。11/15训练两侧即可，不因镜像再重复整堂。

## 动作库真正值得新增的内容

已按248项的中文/英文名及动作说明检索flare、sweep、weight shift、transition、移重、扫腿等，未找到下列**完整目标动作**。相近能力动作已存在，并不计作缺失：`t-flare-side-hold`脚辅助侧撑、`obliques-A`熊爬穿腿、`chest-A`俯卧撑转侧撑、各类L/V撑和坐姿抬腿、`h-quad-cars`、`n-leg-circles`。新增建议要由教练确认技术与制作规格后再进入正式训练库，不据名称批量生成。

| B 高 | 胸朝上直臂后撑、单腿受控扫入/扫出，另一腿与地面支撑；明确左右手不动/卸载时机 | 13→14；桌面式只上下抬髋，后撑滑臀是拉伸，不覆盖腿扫动。 | 2–3组×3–5次/侧，速度由姿态控制；先小范围，不能用大幅甩腿补偿。 |
| C 高 | 托马斯低位辅助半圈：足跟/脚尖允许触地，逐步减少接触，规定9→10→11→12及13→14→15→16的手脚顺序 | 12/16及相邻阶段；熊爬穿腿的弯膝路径与托马斯长腿圆周不同。 | 每组1–3次干净半圈、3–5组，足够休息；成功次数与失败次数分开，不能按视频循环计完成。 |
| D 中 | 两点衔接→半圈→整圈质量练习：脚辅助阶段先行，再进入完整动作；双方向与镜像分别记录 | 全8角度；已有默认托马斯演示不自动等于可训练、可降阶、可计量的技术课。 | 按完成质量与成功次数进阶，初始1–3次/组；连续次数要由教练/实际试练决定，不预设人人10圈。 |

## 证据与判断边界

- [ACSM 2026立场声明（PMID 41843416）](https://pubmed.ncbi.nlm.nih.gov/41843416/)及[官方解读](https://acsm.org/resistance-training-guidelines-update-2026/)支持健康成人规律、个体化抗阻训练；力量训练通常2–3组，力竭不是必要条件。其研究对象与结论不能直接证明某一托马斯角度练法。本文精确剂量据此原则结合动作要求提出，仍属设计推断。
- [Nunes等，动作顺序系统综述/荟萃分析（2020）](https://pubmed.ncbi.nlm.nih.gov/32077380/)发现训练靠前的动作往往获得更大的力量提升；用于支持“目标动作先练”的安排，不代表证明某一托马斯技术最优。
- [Lum与Barbosa，等长训练综述（2019）](https://pubmed.ncbi.nlm.nih.gov/30943568/)支持考虑关节角度与专项需求；据此不应把任何一次静态支撑自动等同于整圈动态能力。本文对阶段迁移不足的判断同时来自现有计划与动作描述，而非把综述结论过度外推。

优先实施顺序：①替换项独立剂量与侧别/交替语义；②清除徒手/居家不可用器械；③初级降阶、高级减重复、目标项前置；④再立项制作A/B/C/D专项衔接，并做用户试练。此次不修改源、不出包、不合并。
