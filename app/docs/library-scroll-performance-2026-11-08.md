# 动作库滑动性能预览（2026-11-08）

用户反馈动作库滑动卡顿。本轮继续在 `codex/ui-hiplab-r3` / `1cd4dd2` 加既有本地整合上修改，保留249范围、筛选设计、现有卡片外观及同行等高。未修改 SDK、Pose-Hub、HipLab 或 iOS；未提交、推送、合入、打标签或发布。

## 修改

- 动作库的惰性行按真实标题、剂量文字及 token 测高，缓存结果后用该行最大高度约束卡片；不再向整棵卡片子树递归查询 intrinsic 高度。宽度、文案、语言、字体、缩放、粗体、文字间距及方向变化时使用新缓存。没有测高回调的旧调用保持原等高布局。
- 静态列表改用 SDK 已有的 `TrainerPoster`，按卡片实际物理宽度解码，保留完整图片及 contain 构图。详情、播放和暂停逻辑保持 SDK 原路径。旧静态卡片本来也未创建视频解码器，不把本次效果归因为减少了正在播放的解码器。
- 补齐249范围内缺失的40张同源封面，原211张字节保持；详见[资产来源](asset-sources.md)。新封面逐项校验当前目录的字节数和 SHA-256，并检查最终 APK 中实际打包字节。

先试用的 `Table` 等高布局仍需两次真实布局，采样 UI 耗时增加，因此已撤去，最终使用缓存文案高度和一次行布局。

## 验证

4个定向文件共28项通过：卡片行高（en/de、浅深、1/1.5/2倍及粗体、不允许 intrinsic 查询）、旧列表/计划及249动作库流程。覆盖249封面存在、40张新增封面目录哈希、AI白名单一致、静态海报实际解码宽度及详情仍走 SDK。`flutter analyze` 无问题；token扫描 owner 外仍 color=8/font=0/radius=5/height50=0，无新增。未扩大到全量测试或重新声明原 SDK ar/hi 大字号问题已修复。

同一台 Android、同为 profile 模式、英文浅色；每版先4次滑动预热，再采3轮×4次同路径滑动。原始记录在本工作树 `output/library-scroll-perf-20261108/frames-{before,after,final}.json`，`after` 是已撤去的 Table 试验。
