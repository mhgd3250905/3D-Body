# 训练计划重构（2026-10-16）

分支 `design/training-redesign`，基于 master `179d971`（L47）。用户授权：学习路径与“今日训练”两块可以最大幅度重构；其他界面只在不丢功能的前提下优化。

## 改了什么

| 原来 | 现在 |
| --- | --- |
| 学习路径：6 阶段、18 课、过关勾选、五项自评，以文字为主 | 「计划」页（首页左上角入口 / 更多 → 计划） |
| 今日训练：当天有效的动作清单，过了当天就清空 | 「我的计划」：长期保存，可命名、可复用 |
| 动作页书签「加入今日训练」 | 「加入计划」：加到已有计划，或用这个动作新建计划 |

### 成套训练
6 个方向：热身激活、肩臂支撑、核心折叠、腿部绕环、侧撑换手、托马斯全链。每套按肌群组定义（`lib/domain/training_plan.dart`）。每个肌群正好各有 A 徒手、B 家用器械、C 健身房三个动作，所以一个场景开关（无器械 / 居家 / 健身房，与训练库共用同一个设置）就能得到每一套的三个版本，不需要新增素材。卡片用这一套第一个动作的视频封面做海报，标明动作数和预计时长。时长是按剂量下限粗算的规划参考，不是测量值。

### 我的计划
- 新建、命名（最多 24 字），多选添加（按点选顺序，已在计划里的动作会显示但不能重复选），拖动把手排序，移出，删除（可撤销）。
- 任何一套成套训练都可以「存为我的计划」，再自己改。

### 开始训练
进度页显示进度条、下一个动作（可以播放示范）和全部动作列表，可以开始、跳过、结束，也可以点列表任意一项跳过去。计时器标题会显示“第 i / n 个”。只有当计时器保存了一条“完成”记录时，这个动作才算练完；中途退出不算。

## 数据
- 本机状态仍是 `version: 1`，新增一个可选字段 `routines: [{id, name, drillIds}]`。旧数据没有这个字段也能直接读取。计划里如果有动作已经不在动作库，只保留还在的动作；一个都不剩的计划会被丢掉。
- 阶段、课程、过关、自评的数据和 Store 接口都保留（不删除用户数据），只是界面不再展示。今日清单字段同样保留。

## 其他界面细节
- 动作详情：剂量和器械改成“标签 + 值”上下两行，避免“3 组 × 每侧 20–30 秒”在窄列里拆行；场景标签用和训练库筛选一样的词（无器械 / 居家 / 健身房）。
- 设置：「托马斯形象」与「语言」「主题」左边对齐。
- 记录：最近记录按结束时间倒序排列。
