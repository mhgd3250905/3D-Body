# 首页视觉基准

2026-10-08 用户明确要求按设计稿保持首页简洁、有质感，去掉底部多排按钮标签。视觉基准是制作包 `03_设计稿/v2_核心流程/h1-home.png` 与对应 HTML；该图是用户最新附件的完整原稿。参考尺寸390×844 pt，PNG780×1688。暂停状态参考同目录 `h2-paused-select`，v2优先于v1概念。

首页采用居中两行标题，左上路径入口，右上更多。顶部约54 pt处开始44 pt高度的控件区；真实系统安全区域参与定位，不在 App 内绘制假状态栏、手机框或底部系统指示条。

人物保留实际 Snow 网格、材质、骨骼和 v33 动作，在上半屏完整展示手脚。左下正面/背面小人体宽148 pt，颜色随当前阶段同步；它是功能位置示意，不宣称精确配准或肌电激活。主播放画面保持干净。包内 `03_设计稿/README.md` 的原句是：`h1/h2 中运动员周围的虚线腿部轨迹不要实现（用户要求主动作画面干净）`，因此不实现稿中的轨迹装饰。

底部只有48 pt圆形播放/暂停、当前阶段、时间和一条八段细时间轴。09–16是源姿态刻度，不是额外常驻按钮排；各刻度中心绑定其实际关键帧时间，刻度之间按原时长插值，使第一侧支撑的2.0秒准确落在11刻度。拖动或键盘左右键定位会暂停播放；时间仍由场景核心统一维护。控件提供滑条语义、数值、增减动作、键盘焦点和触摸拖动。

速度、阶段快速定位、单段循环和镜头操作移入更多；训练库、记录、设置也从更多进入，路径保留左上直接入口。子页面通过返回回到主画面，不显示常驻底部导航。暂停后仍能点击真正人物热点或小人体；右下提示可打开可访问的肌群列表，替代一直铺在底部的肌群标签。

进入训练前后的详情返回保持同一时刻与选中肌群；重新播放才清除选择。修改首页不能破坏这一产品闭环。视觉验收与交互证据归入仓库根 `design-qa.md` 及本目录 `verification.md`，构建成功不能替代实际画面对照。
