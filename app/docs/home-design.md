# 首页视觉基准

2026-10-08 用户明确要求按设计稿保持首页简洁、有质感，去掉底部多排按钮标签。视觉基准是制作包 `03_设计稿/v2_核心流程/h1-home.png` 与对应 HTML；该图是用户最新附件的完整原稿。参考尺寸390×844 pt，PNG780×1688。暂停状态参考同目录 `h2-paused-select`，v2优先于v1概念。

首页采用居中两行标题，左上路径入口，右上更多。顶部约54 pt处开始44 pt高度的控件区；真实系统安全区域参与定位，不在 App 内绘制假状态栏、手机框或底部系统指示条。

人物保留实际 Snow 网格、材质、骨骼和 v33 动作，在上半屏完整展示手脚。左下正面/背面小人体宽148 pt，颜色随当前阶段同步；它是功能位置示意，不宣称精确配准或肌电激活。主播放画面保持干净。包内 `03_设计稿/README.md` 的原句是：`h1/h2 中运动员周围的虚线腿部轨迹不要实现（用户要求主动作画面干净）`，因此不实现稿中的轨迹装饰。

底部只有48 pt圆形播放/暂停、当前阶段、时间和一条八段细时间轴。09–16是源姿态刻度，不是额外常驻按钮排；各刻度中心绑定其实际关键帧时间，刻度之间按原时长插值，使第一侧支撑的2.0秒准确落在11刻度。拖动或键盘左右键定位会暂停播放；时间仍由场景核心统一维护。控件提供滑条语义、数值、增减动作、键盘焦点和触摸拖动。

速度、阶段快速定位、单段循环和镜头操作移入更多；训练库、记录、设置也从更多进入，路径保留左上直接入口。子页面通过返回回到主画面，不显示常驻底部导航。暂停后仍能点击真正人物热点或小人体；右下提示可打开可访问的肌群列表，替代一直铺在底部的肌群标签。

进入训练前后的详情返回保持同一时刻与选中肌群；重新播放才清除选择。修改首页不能破坏这一产品闭环。视觉验收与交互证据归入仓库根 `design-qa.md` 及本目录 `verification.md`，构建成功不能替代实际画面对照。

## 用户确认的两种模型分工

2026-10-08 最终用户要求取消托马斯白膜场景，并取消托马斯身上的高亮。动作人物在首页、详情、卡片预览及自由拖拽下始终使用原上衣、短裤、面孔与原材质；选中肌群只改变详情内容和取景，不改变动作人物外观。首页同步发力卡片继续使用素材包的直立肌群人体，保留原区域划分、细分线和高密度小图。

详情默认大画面显示同一暂停帧的穿衣托马斯，小卡片显示对应部位的直立肌群人体。点击小卡片交换大、小画面，再点切回；没有顶部 segment 或新增模型按钮。正面、背面与复位作用于当前大模型，切换保留各自视角；返回首页保留暂停时刻和选区。深层部位在直立人体上保留细斜线说明；动作人物不显示肌群色区。两种人体继续是独立教学参考，不声称精确配准。

用户随后指出直立人体边线过淡。本轮只优化原分区的描边：在光照与色彩转换后合成细灰线，使高亮区和明亮材质不冲掉线条；保持屏幕线宽上限，修正边界抗锯齿的断续，不恢复宽沟槽或法线浮雕。相同材质同时服务详情大人体、详情小卡片和首页正背小图。最新实看与前后对照见 `output/design-qa/20261008/fine-muscle-lines/`，此前近乎无线的截图不再代表线条质量通过。

最新选区约定仅适用于直立肌群人体：指定肌群详情只显示当前群组的浅红色，不叠加其他阶段的青蓝、粉紫或黄绿色；原细分线保持，选区边缘仅有淡淡阴影。首页同步卡片未选中肌群时仍显示原阶段功能色。原暖米白陶瓷白膜、派生身体/头及动作柔边着色原型归档保留，当前不加载、不挂接、不启用。

两个人体的腰宽不同，动作人物的表面点击命中坐标按真实网格截面及髋、肩锚点修正相对比例，只改教学坐标，不在动作身上着色。校准数据来自 `scene/src/core-calibration.json`，复现与历史完整皮肤采样检查分别为 `calibrate:muscles` 和 `verify:muscles`。这不是精确解剖配准；原网格、法线、骨骼与保存动作保持。
